# CPA 考点速记卡

注册会计师（CPA）六科备考的交互式记忆小卡。点击卡片翻转查看答案，支持按章学习、重点筛选、随机、进度记录、搜索，以及全真模拟考试（单选 / 多选 / 主观题采分点判分）。

> 🌐 **在线访问（手机/电脑均可，任何人可打开）**：
> **https://xiaohuangai.github.io/cpa-cards/**

## 使用方法

### 电脑上用

直接用浏览器打开 `index.html` 即可（双击即可，无需联网、无需服务器）。

### 手机上看

手机无法直接打开电脑上的本地文件，需要先启动本地服务器（手机与电脑连接**同一个 WiFi**）：

1. 双击 `手机访问.bat`（保持窗口开启）；
2. 窗口会显示两行网址，把**「手机打开」那一行**（形如 `http://192.168.x.x:8787`）输入到手机浏览器打开；
3. 若手机打不开，通常是 Windows 防火墙拦截，弹出「允许访问」时点**允许**即可。

> 端口默认 8787，被占用会自动顺延，以窗口实际显示的网址为准。

### 操作说明

- **翻卡**：点击卡片 / 按空格键 / 点「翻转」按钮 → 翻到背面看答案
- **标记已掌握**：翻到卡片**背面**后，点「✅ 已掌握」（或「🔄 再复习」），左侧章节目录进度 +1
- **翻页**：`←` `→` 方向键，或「上一张 / 下一张」按钮
- **筛选**：⭐ 只看重点（4 星及以上）· 📝 未掌握 · 🔀 随机 · ↺ 重置进度
- **搜索**：点右上角「🔍 搜索考点」或按 `/`
- **模拟考试**：点顶部「🎯 模拟考试」选择科目，全真题型（单选 + 多选 + 主观题）、倒计时、答题卡、交卷判分与成绩单
- **明暗主题**：点右上角 🌙 / ☀️ 切换

## 学习进度存储

进度保存在浏览器 `localStorage` 中（本机、同一浏览器），换设备或清除浏览器数据会丢失。

## 模拟考试

点顶部「🎯 模拟考试」进入，六科各一套满分 100 分的全真模拟卷（时长 180 分钟），题型结构与真实 CPA 专业阶段一致：

| 科目 | 单选 | 多选 | 主观题 |
| --- | --- | --- | --- |
| 会计 | 13×2 | 12×2 | 计算分析 2 题 + 综合 2 题 |
| 审计 | 20×1 | 10×2 | 简答 6 题 + 综合 1 题 |
| 财务成本管理 | 13×2 | 12×2 | 计算分析 5 题 + 综合 1 题 |
| 税法 | 24×1 | 14×1.5 | 计算问答 4 题 + 综合 2 题 |
| 经济法 | 24×1 | 14×1.5 | 案例分析 4 题 |
| 公司战略与风险管理 | 24×1 | 14×1.5 | 简答 4 题 + 综合 1 题 |

**判分规则**（对齐真实 CPA）：单选选对得分；多选**必须全对**才得分（少选 / 多选 / 错选均不得分）；主观题按「采分点」机器判分——计算题数字填空（支持容差与千分位）、文字填空、判断选择，逐点得分。交卷后给出百分制得分、各题型得分、用时与错题解析（60 分参考通过线）。最近一次成绩存入 `localStorage`。

## 新增科目数据规范

在 `data/` 下新建 `<科目id>.js`，写入：

```js
window.CPA = window.CPA || {};
window.CPA.chapters = window.CPA.chapters || {};
window.CPA.chapters['<科目id>'] = [
  {
    id: 'ch01',            // 章节唯一 ID
    title: '章节名',        // 不含"第X章"
    summary: '一句话概括',
    cards: [
      {
        front: '正面提问 / 考点',
        back: '背面详解（\n 换行，**加粗** 高亮）',
        mnemonic: '记忆口诀（可选）',
        star: 5,            // 重要度 1~5，>=4 视为"重点"
        tags: ['标签'],      // 可选
      },
    ],
  },
];
```

然后在 `index.html` 底部按顺序引入 `<script src="data/<科目id>.js"></script>`，
并把 `data/subjects.js` 中该科目的 `status` 由 `'todo'` 改为 `'ready'`。
